==============================================================================
SUPPORTED FORMATS
==============================================================================

VoxelForge is designed to support multiple voxel ecosystems through a modular
Import / Export architecture.

Every format is implemented independently.

==============================================================================

CURRENTLY SUPPORTED ECOSYSTEMS

Minecraft

Bloxd.io

==============================================================================

MINECRAFT

Supported formats include:

Minecraft Schematic.

Minecraft Litematic.

Future Minecraft formats may be added without modifying existing Importers or
Exporters.

==============================================================================

BLOXD.IO

Supported format:

.bloxdschem

The Bloxd implementation follows the reverse-engineered Schema Version 0
binary format.

==============================================================================

FORMAT CHARACTERISTICS

Minecraft formats use block palettes and metadata structures specific to each
format.

Bloxd.io uses:

Fixed chunk size (32×32×32).

Avro binary serialization.

Run-Length Encoding (RLE).

Unsigned LEB128 integer encoding.

Chunk-based storage.

==============================================================================

UNIVERSAL CONVERSION

Every supported format follows the same conversion path.

External Format

↓

Importer

↓

Universal Block Database

↓

Voxel World

↓

Universal Block Database

↓

Exporter

↓

External Format

Direct conversion between two external formats is forbidden.

==============================================================================

VERSION COMPATIBILITY

Each Importer and Exporter defines the versions it supports.

Unsupported versions should generate explicit compatibility errors.

==============================================================================

FUTURE FORMATS

Future supported formats may include:

Minetest.

Vintage Story.

Cube World Editors.

Custom Studio Formats.

Additional proprietary formats.

The architecture must remain open for future expansion.

==============================================================================

DESIGN OBJECTIVE

Every supported format should integrate into VoxelForge through the same
Importer / Exporter architecture while remaining completely isolated from
the Core engine.

==============================================================================

END OF SUPPORTED FORMATS
