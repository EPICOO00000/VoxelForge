==============================================================================
METADATA CONVERSION
==============================================================================

Metadata Conversion defines how per-voxel information is translated between
VoxelForge and external voxel formats.

Metadata is converted independently from Universal Block IDs.

==============================================================================

PURPOSE

The Metadata Conversion System preserves information that cannot be represented
by Block IDs or Block States alone.

Whenever supported by the target format, metadata should be preserved.

==============================================================================

SUPPORTED METADATA

Examples include:

Custom Names.

Text.

Inventory Contents.

Ownership Information.

Lock State.

Script Data.

Plugin Data.

Custom Properties.

==============================================================================

Target Metadata

==============================================================================

VALIDATION

Metadata must be validated before insertion into the Voxel World.

Invalid metadata should never corrupt imported worlds.

==============================================================================

UNSUPPORTED METADATA

If the destination format does not support specific metadata:

The exporter should:

Generate a warning.

Skip unsupported fields.

Preserve all remaining valid data.

Export should never fail solely because of unsupported metadata.

==============================================================================

PLUGIN METADATA

Plugins may register additional metadata schemas.

Plugin metadata must remain isolated from the Core.

==============================================================================

VERSION SUPPORT

Metadata converters may vary depending on the target format version.

Version-specific conversion belongs to Importers and Exporters.

==============================================================================

DESIGN OBJECTIVE

Metadata conversion should maximize information preservation while maintaining
compatibility between different voxel ecosystems.
