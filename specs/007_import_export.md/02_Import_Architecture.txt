==============================================================================
IMPORT ARCHITECTURE
==============================================================================

The Import Architecture defines how external voxel data enters VoxelForge.

Importers translate external formats into the engine's internal world
representation.

==============================================================================

==============================================================================

SUPPORTED IMPORTERS

The first Importers include:

Minecraft Schematic Importer.

Minecraft Litematic Importer.

Bloxd.io Schematic Importer.

==============================================================================

DESIGN PRINCIPLES

Every Importer must remain:

Independent.

Stateless.

Deterministic.

Reusable.

==============================================================================

BLOCK CONVERSION

External block identifiers are translated into Universal Block IDs through
the Block Database.

Importers never register blocks directly.

==============================================================================

STATE CONVERSION

Game-specific block states are converted into Universal States defined by the
Block Database.

==============================================================================

METADATA CONVERSION

Importer-specific metadata is translated into the internal metadata model
whenever supported.

Unsupported metadata should generate warnings rather than silently failing.

==============================================================================

FORMAT VALIDATION

Every imported file must be validated before constructing the Voxel World.

Validation includes:

Header validation.

Version validation.

Chunk integrity.

Block integrity.

Metadata integrity.

==============================================================================

ERROR HANDLING

Recoverable errors should produce warnings.

Corrupted files should abort the import safely without modifying the current
Voxel World.

==============================================================================

DESIGN OBJECTIVE

Importers should convert external voxel formats into the internal engine
representation while remaining completely independent from rendering,
editing and gameplay systems.

==============================================================================
