==============================================================================
BRUSH PERFORMANCE
==============================================================================

Brush Performance defines the optimization strategies used to maintain
interactive editing performance regardless of world size.

Performance optimization must never change editing results.

==============================================================================

PURPOSE

The Brush System should remain responsive when editing worlds containing
millions or even billions of voxels.

==============================================================================

DESIGN PRINCIPLES

Performance optimizations must remain:

Deterministic.

Transparent.

Modular.

Scalable.

Measurable.

==============================================================================

PERFORMANCE PRIORITIES

Optimization priorities are:

Correctness.

Determinism.

Memory Locality.

CPU Cache Efficiency.

Parallelism.

Raw Speed.

==============================================================================

CHUNK PROCESSING

Brush execution should operate on chunks independently.

Only intersecting chunks should be processed.

Non-intersecting chunks must never be evaluated.

==============================================================================

BOUNDING VOLUMES

Every execution begins with bounding volume rejection.

No voxel outside the Brush AABB should ever be tested.

==============================================================================

SPARSE EXECUTION

Empty chunks should be skipped immediately.

Large empty regions must require almost no computation.

==============================================================================

VECTORIZATION

Whenever possible, voxel operations should execute on contiguous NumPy arrays.

Python voxel-by-voxel loops should be avoided.

==============================================================================

CACHE LOCALITY

Sequential memory access should always be preferred.

Random memory access should be minimized.

==============================================================================

MEMORY ALLOCATION

Temporary allocations should be reused.

Large temporary buffers should be pooled.

Repeated allocation inside Brush execution is discouraged.

==============================================================================

MULTITHREADING

Independent chunks may execute simultaneously.

Synchronization should occur only during commit.

==============================================================================

DIRTY REGIONS

Only modified chunks become Dirty.

Rendering and History should never process unchanged chunks.

==============================================================================

ADAPTIVE EXECUTION

Future versions may dynamically adjust sampling density according to:

Brush Radius.

Cursor Speed.

System Performance.

==============================================================================

SIMD

Future implementations may leverage SIMD instructions for:

Sampling.

Falloff.

Voxel comparisons.

==============================================================================

GPU COMPUTATION

GPU acceleration may be introduced for:

Sampling.

Noise generation.

Distance field evaluation.

Massive procedural brushes.

GPU acceleration must remain optional.

==============================================================================

PROFILING

Every expensive Brush stage should expose profiling information.

Performance bottlenecks should be measurable.

==============================================================================

BENCHMARKS

The project should maintain standardized benchmarks for:

Brush latency.

Chunk throughput.

Memory usage.

Large world performance.

==============================================================================

SCALABILITY

Performance should scale approximately linearly with the number of modified
voxels.

World size alone should not significantly affect editing latency.

==============================================================================

DESIGN OBJECTIVE

Brushes should remain interactive even inside extremely large voxel worlds
while preserving deterministic execution.

==============================================================================

END OF BRUSH PERFORMANCE
