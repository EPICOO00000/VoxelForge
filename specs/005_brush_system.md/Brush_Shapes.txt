==============================================================================
BRUSH SHAPES
==============================================================================

Brush Shapes define the spatial influence of a brush.

Shapes determine which voxels may be modified.

Shapes never determine how voxels are modified.

==============================================================================

PURPOSE

Brush Shapes provide reusable geometric definitions that can be combined
with any Brush Behavior.

This separation minimizes duplicated logic.

==============================================================================

DESIGN PRINCIPLES

Brush Shapes must remain:

Pure.

Deterministic.

Stateless.

Independent.

Reusable.

==============================================================================

RESPONSIBILITIES

A Brush Shape is responsible only for:

Defining geometric influence.

Generating sampling volumes.

Providing spatial queries.

It never performs voxel modifications.

==============================================================================

SUPPORTED SHAPES

Core shapes include:

Sphere.

Cube.

Cylinder.

Cone.

Capsule.

Plane.

Line.

Custom Shape.

Future versions may introduce additional shapes.

==============================================================================

SHAPE PARAMETERS

Typical parameters include:

Radius.

Height.

Length.

Orientation.

Rotation.

Offset.

Custom Scale.

==============================================================================

LOCAL SPACE

Shapes are evaluated inside their own local coordinate system.

Transformation into world space occurs before sampling.

==============================================================================

ROTATION

Brush Shapes may support arbitrary rotation.

Rotation handling must remain independent from Brush Behaviors.

==============================================================================

BOUNDING VOLUME

Every Shape must provide a Bounding Volume.

Bounding Volumes accelerate sampling and intersection tests.

==============================================================================

CONTAINS QUERY

Every Shape must implement a deterministic spatial query.

Example:

Contains(Point)

Returns:

Inside.

Outside.

Boundary.

==============================================================================

DISTANCE QUERY

Shapes should expose a normalized distance function.

Distance values are used by:

Falloff.

Preview.

Future procedural modifiers.

==============================================================================

CUSTOM SHAPES

Users and plugins may define custom Brush Shapes.

Custom Shapes must implement the same public interface as built-in shapes.

==============================================================================

COMPOSITION

Future versions may combine multiple Shapes.

Examples include:

Union.

Intersection.

Difference.

Layered Shapes.

==============================================================================

PERFORMANCE

Shape evaluation should avoid unnecessary calculations.

Bounding volumes should eliminate irrelevant voxels before detailed testing.

==============================================================================

DETERMINISM

Identical Shape parameters must always generate identical spatial influence.

==============================================================================

EXTENSIBILITY

Adding a new Shape should never require modification of the Brush Engine.

==============================================================================

DESIGN OBJECTIVE

Brush Shapes should provide a flexible geometric foundation capable of
supporting every present and future editing tool.

==============================================================================

END OF BRUSH SHAPES
