==============================================================================
BRUSH PRESETS
==============================================================================

Brush Presets store reusable Brush configurations.

A Preset represents parameter values only.

It never duplicates Brush implementations.

==============================================================================

PURPOSE

Presets allow artists to quickly switch between frequently used Brush
configurations.

==============================================================================

PRESET CONTENT

A Preset may contain:

Brush Identifier.

Parameter Values.

Falloff.

Spacing.

Preview Options.

Metadata.

==============================================================================

METADATA

Every Preset should include:

Name.

Description.

Author.

Creation Date.

Version.

Category.

Tags.

Thumbnail (optional).

==============================================================================

PRESET LIBRARY

Presets may be organized into folders and categories.

Examples:

Terrain.

Architecture.

Organic.

Painting.

Procedural.

Favorites.

==============================================================================

IMPORT / EXPORT

Presets should support:

Saving.

Loading.

Sharing.

Version Migration.

==============================================================================

DEFAULT PRESETS

The engine should ship with a curated set of default presets.

These presets serve as examples and learning resources.

==============================================================================

USER PRESETS

Users may freely create, edit and delete personal presets.

==============================================================================

SEARCH

Preset libraries should support:

Search.

Tags.

Favorites.

Sorting.

Filtering.

==============================================================================

VERSIONING

Old presets should remain usable whenever practical.

Migration should occur automatically whenever possible.

==============================================================================

DESIGN OBJECTIVE

Brush Presets should provide a reusable and shareable workflow while keeping
Brush implementations completely independent from stored configurations.

==============================================================================
