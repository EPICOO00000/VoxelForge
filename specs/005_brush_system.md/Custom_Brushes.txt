==============================================================================
CUSTOM BRUSHES
==============================================================================

Custom Brushes allow users and plugins to extend the Brush System without
modifying the engine.

==============================================================================

PURPOSE

The engine must never restrict brush creation to built-in implementations.

Every Brush should be replaceable or extendable.

==============================================================================

DESIGN PRINCIPLES

Custom Brushes must remain:

Sandboxed.

Deterministic.

Version Compatible.

Independent from internal engine implementation.

==============================================================================

REGISTRATION

Every Custom Brush must register itself through the Brush Registry.

Registration includes:

Unique Identifier.

Display Name.

Version.

Author.

Category.

Supported Parameters.

Supported Behaviors.

==============================================================================

INTERFACES

Every Custom Brush implements the standard Brush interface.

No special execution pipeline exists for custom implementations.

==============================================================================

PARAMETERS

Custom Brushes may expose any number of custom parameters.

Parameters automatically appear inside the Brush UI.

==============================================================================

PREVIEW

Custom Brushes may implement custom preview rendering.

If omitted, the default preview system is used.

==============================================================================

DEPENDENCIES

Custom Brushes must never access:

Renderer internals.

History internals.

Chunk storage.

Low-level memory structures.

==============================================================================

VERSIONING

Brushes should expose their supported API version.

Deprecated APIs should remain compatible whenever practical.

==============================================================================

PLUGIN SUPPORT

Plugins may register:

Brush Shapes.

Brush Behaviors.

Brush Parameters.

Brush Presets.

Preview Modes.

==============================================================================

DESIGN OBJECTIVE

The Brush System should remain open for extension while protecting engine
stability and long-term compatibility.

==============================================================================

END OF CUSTOM BRUSHES
