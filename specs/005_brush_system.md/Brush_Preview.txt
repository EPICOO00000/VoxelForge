==============================================================================
BRUSH PREVIEW
==============================================================================

The Brush Preview System provides real-time visual feedback before Brush
execution.

Preview assists the user without modifying the Voxel World.

==============================================================================

PURPOSE

Users should always understand the expected Brush effect before applying it.

The Preview System visualizes Brush influence independently from editing.

==============================================================================

DESIGN PRINCIPLES

The Preview System must remain:

Real-time.

Deterministic.

Non-destructive.

Independent from Brush Behaviors.

==============================================================================

PREVIEW TYPES

The system may provide several preview modes.

Examples include:

Outline.

Volume.

Surface Projection.

Affected Voxels.

Influence Gradient.

Brush Orientation.

Future preview modes.

==============================================================================

UPDATE CONDITIONS

The Preview updates whenever:

Cursor Position changes.

Brush changes.

Parameter changes.

Shape changes.

Radius changes.

Falloff changes.

==============================================================================

NON-DESTRUCTIVE

Preview never modifies:

Voxel World.

History.

Renderer State.

Project Data.

==============================================================================

SAMPLING

Preview should reuse the Brush Sampling system whenever practical.

Duplicated sampling implementations should be avoided.

==============================================================================

FALLOFF VISUALIZATION

Preview may visualize influence intensity.

Possible methods include:

Opacity.

Gradient.

Heat Map.

Color Scale.

==============================================================================

PERFORMANCE

Preview must remain interactive.

Expensive calculations should be simplified when necessary.

==============================================================================

CACHING

Reusable preview geometry should be cached whenever practical.

Only changed information should be regenerated.

==============================================================================

VIEWPORT INTEGRATION

Preview integrates with the Blender Viewport.

The preview should remain visually distinct from rendered geometry.

==============================================================================

VISIBILITY

Preview should automatically hide when:

No active Brush exists.

Editing is disabled.

The cursor leaves the editable area.

==============================================================================

THREADING

Preview generation may execute independently from rendering.

Final viewport drawing follows Blender restrictions.

==============================================================================

CUSTOM PREVIEWS

Plugins may provide custom preview implementations.

Custom previews should integrate through the same public interfaces.

==============================================================================

FUTURE FEATURES

Future implementations may support:

Animated previews.

Pressure visualization.

Stroke prediction.

Live procedural previews.

GPU previews.

==============================================================================

DESIGN OBJECTIVE

The Preview System should provide immediate, accurate and intuitive visual
feedback while remaining lightweight enough for continuous real-time editing.

==============================================================================

END OF BRUSH PREVIEW
