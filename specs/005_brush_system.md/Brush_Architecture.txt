==============================================================================
BRUSH ARCHITECTURE
==============================================================================

The Brush System follows a layered architecture.

Each layer has a single responsibility.

Higher layers coordinate execution.

Lower layers perform specialized work.

==============================================================================

ARCHITECTURE

User Input

↓

Brush Operator

↓

Brush Engine

↓

Brush Shape

↓

Brush Sampling

↓

Brush Behavior

↓

Voxel World

↓

History System

↓

Event System

↓

Renderer

==============================================================================

LAYER RESPONSIBILITIES

Brush Operator

Receives user input.

Reads UI parameters.

Creates execution requests.

Never edits voxels.

==============================================================================

Brush Engine

Coordinates the complete execution pipeline.

Validates execution.

Schedules operations.

Creates history entries.

Dispatches events.

==============================================================================

Brush Shape

Defines spatial influence.

Examples:

Sphere.

Cube.

Cylinder.

Cone.

Custom Shapes.

Brush Shapes never modify voxels.

==============================================================================

Brush Sampling

Determines which voxels belong to the brush influence.

Sampling converts abstract shapes into voxel coordinates.

==============================================================================

Brush Behavior

Defines how affected voxels are modified.

Examples:

Paint.

Replace.

Fill.

Erase.

Smooth.

Noise.

Flatten.

Raise.

Lower.

Brush Behaviors never determine brush shape.

==============================================================================

Voxel World

Stores all voxel data.

Applies validated modifications.

Marks affected chunks as dirty.

==============================================================================

History System

Records every voxel modification.

Provides Undo and Redo support.

==============================================================================

Event System

Notifies interested systems.

Examples include:

Renderer.

Statistics.

Autosave.

Future plugins.

==============================================================================

Renderer

Rebuilds modified chunks.

Never modifies voxel data.

==============================================================================

DEPENDENCY RULES

Brush Shapes must never know Brush Behaviors.

Brush Behaviors must never know Brush Shapes.

Brushes never communicate with the Renderer.

Brushes never communicate with Importers.

Brushes never communicate with Exporters.

==============================================================================

DESIGN OBJECTIVE

Brush execution should remain modular, deterministic and independent from all
rendering and export systems.

==============================================================================

END OF BRUSH ARCHITECTURE
