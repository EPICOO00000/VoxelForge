==============================================================================
UNIVERSAL BLOCK IDS
==============================================================================

Universal Block IDs define the unique identifiers used internally by the
VoxelForge engine.

Every voxel stored inside the Voxel World references only a Universal Block ID.

Game-specific identifiers must never be stored inside the Core.

==============================================================================

PURPOSE

Universal Block IDs provide a stable abstraction layer between the engine
and every supported voxel game.

This allows the same world to be exported to multiple games without changing
the underlying voxel data.

==============================================================================

DESIGN PRINCIPLES

Universal IDs must remain:

Unique.

Immutable.

Deterministic.

Compact.

Fast to compare.

Independent from external formats.

==============================================================================

ID FORMAT

Universal Block IDs are unsigned integer values.

The exact storage type is implementation dependent but should prioritize
memory efficiency.

The initial implementation should support at least 65,536 unique block
definitions.

==============================================================================

RESERVED IDS

ID 0 is permanently reserved for Air.

Additional reserved IDs may include:

Unknown Block.

Missing Block.

Invalid Block.

Debug Block.

Reserved IDs must never change between versions.

==============================================================================

IMMUTABILITY

Once assigned, a Universal Block ID must never be reused for another block.

Removing a block definition must not recycle its identifier.

==============================================================================

LOOKUP

Universal IDs provide constant-time lookup through the Block Registry.

Lookup performance should remain independent from the total number of blocks.

==============================================================================

PERSISTENCE

Voxel Worlds store only Universal Block IDs.

Saved projects must never store game-specific identifiers.

==============================================================================

IMPORT

Importers translate external block identifiers into Universal Block IDs.

Unknown identifiers should resolve to the Missing Block definition.

==============================================================================

EXPORT

Exporters translate Universal Block IDs into game-specific identifiers.

If no valid mapping exists, exporter fallback rules are applied.

==============================================================================

PLUGIN SUPPORT

Plugins may register additional Universal Block IDs through the Block
Registry.

Plugin identifiers must never conflict with existing definitions.

==============================================================================

DESIGN OBJECTIVE

Universal Block IDs provide a permanent, stable and game-independent
identifier system shared by every subsystem.

==============================================================================

END OF UNIVERSAL BLOCK IDS
