==============================================================================
BLOCK TEXTURES
==============================================================================

Block Textures define the visual appearance associated with Block Definitions.

Textures belong to Block Definitions.

Textures never belong to voxel instances.

==============================================================================

PURPOSE

The Texture System provides renderer-independent visual information while
remaining separate from geometry generation.

==============================================================================

DESIGN PRINCIPLES

Textures must remain:

Renderer Independent.

Game Independent.

Data Driven.

Replaceable.

Extensible.

==============================================================================

TEXTURE SET

A Block Definition may reference one or more textures.

Examples include:

Top.

Bottom.

Side.

Front.

Back.

Left.

Right.

==============================================================================

TEXTURE REFERENCES

Textures should be referenced through stable identifiers rather than file
paths.

The Asset System resolves identifiers into physical resources.

==============================================================================

ATLAS SUPPORT

Multiple textures may be packed into texture atlases.

Atlas generation remains independent from Block Definitions.

==============================================================================

ANIMATED TEXTURES

Future implementations may support animated texture definitions.

Animation data belongs to texture resources, not Block Definitions.

==============================================================================

PBR SUPPORT

Future rendering systems may support:

Albedo.

Normal Maps.

Roughness.

Metallic.

Emission.

==============================================================================

PLUGIN SUPPORT

Plugins may register additional textures and texture sets.

==============================================================================

DESIGN OBJECTIVE

The Texture System should provide flexible visual definitions while remaining
independent from rendering implementation and game-specific formats.

==============================================================================

END OF BLOCK TEXTURES
