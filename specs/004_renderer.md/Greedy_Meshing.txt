==============================================================================
GREEDY MESHING
==============================================================================

Greedy Meshing is the primary geometry optimization algorithm used by the
Render System.

Its purpose is to merge adjacent coplanar voxel faces into larger polygons,
dramatically reducing polygon count while preserving the visual appearance
of the voxel world.

==============================================================================

PURPOSE

Naively rendering one quad per visible voxel face produces an excessive
number of polygons.

Greedy Meshing reduces geometry complexity by combining neighboring faces
whenever possible.

The visual result remains identical.

==============================================================================

DESIGN PRINCIPLES

Greedy Meshing must remain:

Deterministic.

Lossless.

Chunk-local.

Cache-friendly.

Independent from Blender.

==============================================================================

INPUT

The algorithm receives the visible faces produced by Face Culling.

Invisible faces are never processed.

==============================================================================

MERGE CONDITIONS

Two faces may be merged only if every compatibility rule is satisfied.

Compatible faces must share:

Same plane.

Same orientation.

Same block identifier.

Same material.

Same texture.

Same UV rules.

Same transparency group.

Same rendering properties.

Future properties may extend compatibility requirements.

==============================================================================

MERGE RESTRICTIONS

Faces must never be merged if doing so changes visual output.

Examples include:

Different textures.

Different rotations.

Different UV mapping.

Different lighting behavior.

Different transparency.

Different metadata.

Visual correctness always has priority.

==============================================================================

SCAN STRATEGY

The algorithm processes one slice at a time.

Each slice is converted into a temporary visibility mask.

The mask is scanned to locate maximal mergeable rectangles.

Merged regions become single polygons.

==============================================================================

RECTANGLE EXPANSION

Expansion proceeds until any compatibility rule fails.

The produced rectangle should always be maximal.

Partial merging should be avoided whenever possible.

==============================================================================

FACE ORIENTATION

Each face orientation is processed independently.

Positive X.

Negative X.

Positive Y.

Negative Y.

Positive Z.

Negative Z.

==============================================================================

CHUNK BOUNDARIES

Greedy Meshing operates inside a single chunk.

Faces are never merged across chunk boundaries.

Chunk independence greatly simplifies incremental rebuilding.

==============================================================================

OUTPUT

The algorithm produces optimized polygon descriptions.

Each polygon contains:

Vertex positions.

Face orientation.

Material reference.

UV information.

Normal direction.

Additional rendering metadata.

==============================================================================

DETERMINISM

Identical voxel input must always produce identical polygon output.

No random behavior is permitted.

==============================================================================

PERFORMANCE

Greedy Meshing executes for every rebuilt chunk.

The implementation should maximize:

Sequential memory access.

Cache locality.

Vectorized preprocessing.

Minimal branching.

==============================================================================

MEMORY

Temporary masks should be reused whenever possible.

Repeated allocations should be minimized.

==============================================================================

THREAD SAFETY

Independent chunks may execute Greedy Meshing simultaneously.

Temporary buffers must never be shared unsafely.

==============================================================================

FUTURE IMPROVEMENTS

Future implementations may introduce:

SIMD acceleration.

GPU preprocessing.

Parallel slice processing.

Advanced rectangle search.

These improvements should not modify the public renderer interface.

==============================================================================

DESIGN OBJECTIVE

Greedy Meshing should reduce polygon count by several orders of magnitude
while preserving an identical rendered result.

==============================================================================

END OF GREEDY MESHING
