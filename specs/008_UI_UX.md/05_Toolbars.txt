==============================================================================
TOOLBARS
==============================================================================

Toolbars provide immediate access to the most frequently used editing tools.

Frequently used operations should require at most one click.

==============================================================================

PURPOSE

Toolbars minimize navigation and maximize editing efficiency.

==============================================================================

PRIMARY TOOLS

The main toolbar should include:

Select.

Place.

Erase.

Paint.

Fill.

Replace.

Line.

Box.

Sphere.

Cylinder.

Copy.

Paste.

Undo.

Redo.

==============================================================================

SECONDARY TOOLS

Additional tools may include:

Mirror.

Rotate.

Move.

Scale.

Measure.

Chunk Inspector.

==============================================================================

ICON DESIGN

Icons should remain:

Simple.

Recognizable.

Consistent.

Scalable.

Compatible with Blender's visual language.

==============================================================================

CUSTOMIZATION

Future versions may allow users to:

Hide tools.

Reorder tools.

Create custom toolbars.

Save toolbar layouts.

==============================================================================

SHORTCUT INDICATION

Whenever practical, toolbar buttons should display their associated keyboard
shortcut.

==============================================================================

DESIGN OBJECTIVE

Toolbars should provide immediate access to the most common voxel editing
operations while minimizing interface clutter.

==============================================================================

END OF TOOLBARS
