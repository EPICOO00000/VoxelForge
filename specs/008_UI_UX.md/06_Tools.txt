==============================================================================
TOOLS
==============================================================================

Tools represent the primary interaction methods used to modify Voxel Worlds.

Each tool performs one well-defined editing task.

==============================================================================

DESIGN PRINCIPLES

Every tool should be:

Predictable.

Deterministic.

Responsive.

Undoable.

Reusable.

==============================================================================

CORE TOOLS

Initial implementation includes:

Place Tool.

Erase Tool.

Paint Tool.

Replace Tool.

Fill Tool.

Line Tool.

Box Tool.

Sphere Tool.

Cylinder Tool.

Selection Tool.

==============================================================================

TOOL LIFECYCLE

Tool Selected

↓

User Input

↓

Preview Update

↓

Validation

↓

Execute Operation

↓

History Recording

↓

Viewport Refresh

==============================================================================

TOOL SETTINGS

Each tool exposes only the parameters relevant to its operation.

Examples include:

Radius.

Shape.

Block Type.

Replace Filter.

Fill Rules.

==============================================================================

PREVIEW

Whenever possible, tools should provide a real-time viewport preview before
modifying the world.

The preview must never modify voxel data.

==============================================================================

UNDO SUPPORT

Every tool operation must generate a History entry.

No editing operation is exempt from Undo and Redo.

==============================================================================

PLUGIN SUPPORT

Plugins may register additional tools.

Custom tools follow the same lifecycle as built-in tools.

==============================================================================

DESIGN OBJECTIVE

The Tool System should provide a fast, intuitive and consistent editing
experience while remaining fully integrated with the engine architecture.

==============================================================================
