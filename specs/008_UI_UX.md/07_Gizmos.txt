==============================================================================
GIZMOS
==============================================================================

Gizmos provide direct visual manipulation tools inside the Blender Viewport.

They allow users to interact with voxel data without relying exclusively on
panels or menus.

==============================================================================

PURPOSE

Gizmos provide intuitive visual controls for editing operations.

They should reduce unnecessary mouse movement and improve editing precision.

==============================================================================

DESIGN PRINCIPLES

Every Gizmo must be:

Responsive.

Non-Intrusive.

Context Aware.

Easy to Understand.

Consistent with Blender.

==============================================================================

SUPPORTED GIZMOS

Initial Gizmos include:

Selection Gizmo.

Move Gizmo.

Rotate Gizmo.

Scale Gizmo.

Brush Radius Gizmo.

Brush Direction Indicator.

Selection Bounds.

==============================================================================

VISIBILITY

Only relevant Gizmos should be displayed.

Unused Gizmos should remain hidden.

Viewport clutter must be minimized.

==============================================================================

INTERACTION

Gizmos must support:

Mouse Hover.

Click.

Drag.

Precision Movement.

Snapping.

==============================================================================

VISUAL FEEDBACK

Interactive Gizmos should visually indicate:

Hover State.

Active State.

Disabled State.

Locked State.

==============================================================================

SELECTION GIZMO

The Selection Gizmo manipulates the active voxel selection.

It supports:

Translation.

Rotation.

Scaling.

==============================================================================

BRUSH GIZMO

The Brush Gizmo visualizes:

Brush Position.

Brush Radius.

Brush Shape.

Brush Orientation.

The preview updates continuously while the cursor moves.

==============================================================================

PLUGIN SUPPORT

Plugins may register custom Gizmos.

Custom Gizmos must follow the same interaction rules.

==============================================================================

DESIGN OBJECTIVE

Gizmos should make voxel editing feel natural by providing intuitive visual
controls directly inside the Viewport.

==============================================================================

END OF GIZMOS
