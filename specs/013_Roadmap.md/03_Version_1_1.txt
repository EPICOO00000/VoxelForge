# Version 1.1

## Objective

Version 1.1 should improve the usability, performance, compatibility, and extensibility of the stable Version 1.0 foundation.

Version 1.1 should focus primarily on refinement rather than replacing the core architecture.

## Stability Improvements

Version 1.1 should address issues discovered after Version 1.0.

Priority should be given to:

- Crash fixes.
- Data integrity fixes.
- Import/export fixes.
- Rendering fixes.
- UI reliability.
- Undo/redo reliability.
- Plugin API stability.
- Regression prevention.

Previously fixed bugs should remain protected by regression tests.

## Performance Improvements

Version 1.1 should improve performance based on real profiling data.

Potential areas include:

- Chunk generation.
- Mesh generation.
- Render updates.
- Brush operations.
- Large selections.
- Import/export.
- Save/load.
- Memory allocation.
- Cache behavior.

Optimizations should only be introduced when their impact can be measured.

Performance changes must preserve existing behavior.

## Editing Improvements

Version 1.1 may expand the editing workflow with improvements such as:

- More efficient brush operations.
- Improved selection handling.
- Better editing feedback.
- Improved large-operation handling.
- Better undo/redo behavior.
- Improved navigation.

Any new editing behavior must remain consistent with the existing brush and world specifications.

## Rendering Improvements

Version 1.1 may improve the renderer through:

- More efficient mesh updates.
- Better visibility handling.
- Improved chunk loading behavior.
- Improved transparency handling.
- Improved render caching.
- Better handling of large scenes.

Renderer changes must preserve the separation between authoritative world data and derived render data.

## Import and Export Improvements

Version 1.1 should improve compatibility and robustness of existing import/export workflows.

Potential improvements include:

- Better validation.
- Clearer import errors.
- Better unsupported-block handling.
- Improved large-structure processing.
- Faster conversion.
- Improved multi-file export handling.

For Bloxd.io exports, the 200-chunk-per-schematic limit remains mandatory.

Large structures must continue to be split into valid individual schematic files.

## UI Improvements

Version 1.1 should refine the user experience based on Version 1.0 usage.

Potential areas include:

- Improved tool organization.
- Better property controls.
- Better status feedback.
- Improved error messages.
- Improved keyboard shortcuts.
- Improved accessibility.
- Improved workspace management.

UI improvements must not introduce unnecessary coupling between presentation and core world systems.

## Plugin API Evolution

Version 1.1 may expand the Plugin API based on practical requirements discovered during Version 1.0 development.

New API features should:

- Follow the existing API architecture.
- Be documented.
- Be tested.
- Have clear ownership.
- Avoid exposing unnecessary internal implementation details.

Potentially unstable experimental functionality should not automatically become a permanent public API.

## Compatibility

Version 1.1 should preserve supported Version 1.0 project and workflow compatibility whenever possible.

Any intentional compatibility change must be documented before release.

External-format compatibility should be protected through automated fixtures and regression tests.

## Testing Expansion

Version 1.1 should expand automated coverage where Version 1.0 exposed weaknesses.

Additional tests should be added for:

- Newly discovered edge cases.
- Large worlds.
- Large brush operations.
- Large imports/exports.
- Renderer edge cases.
- Plugin interactions.
- Performance regressions.
- Compatibility regressions.

## Release Criteria

Version 1.1 should be considered ready when:

- Version 1.0 functionality remains stable.
- Planned improvements are implemented and tested.
- No known critical regression remains unresolved.
- Performance improvements are validated.
- Compatibility tests pass.
- CI passes the required release suite.

## Version 1.1 Principle

Version 1.1 should make VoxelForge significantly more polished without destabilizing the foundation established by Version 1.0.
