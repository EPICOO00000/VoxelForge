# Project Vision

VoxelForge is a professional voxel creation engine integrated into Blender.

It is **not** a Minecraft addon.

It is **not** a Blender modeling addon.

VoxelForge is a complete voxel editing platform capable of creating,
editing, rendering and exporting voxel worlds to multiple games.

Minecraft is only one supported export format.

Bloxd.io is only one supported export format.

Future games may be supported without modifying the engine itself.

The project must always remain game-agnostic.

==============================================================================

# Mission

Provide the most powerful voxel creation environment available inside Blender.

VoxelForge must combine:

• Blender's modeling capabilities

• Professional voxel editing

• Real-time terrain manipulation

• Procedural generation

• High performance rendering

• Universal export system

The user should be able to build an entire world without ever launching a game.

==============================================================================

# Long-Term Vision

VoxelForge is intended to become the reference voxel editor for creators.

The project must eventually support:

- Minecraft Java
- Minecraft Bedrock
- Bloxd.io
- Minetest
- Vintage Story
- Custom voxel formats

Additional exporters must be implemented as plugins whenever possible.

==============================================================================

# Design Philosophy

Every architectural decision must follow these principles.

Priority order:

1. Simplicity
2. Performance
3. Scalability
4. Extensibility
5. Maintainability

Never sacrifice maintainability for short-term convenience.

==============================================================================

# Core Philosophy

VoxelForge manipulates voxels.

VoxelForge does not manipulate Blender meshes.

VoxelForge does not manipulate Minecraft blocks.

Everything inside the engine is represented using abstract voxels.

Games are only translators.

==============================================================================

# Golden Rules

The following rules are absolute.

They must never be violated.

• The engine is completely independent from Blender.

• The engine is completely independent from Minecraft.

• Blender is only the graphical interface.

• Minecraft is only an exporter.

• Bloxd.io is only an exporter.

• Every module must remain replaceable.

• Every subsystem must be independently testable.

==============================================================================

# Target Users

VoxelForge is designed for:

• Minecraft builders

• Bloxd.io builders

• Map creators

• Terrain artists

• Procedural generation enthusiasts

• Technical artists

• Blender users

==============================================================================

# Primary Goals

The engine must allow users to:

• Create terrains

• Sculpt terrain

• Paint blocks

• Generate caves

• Generate rivers

• Generate cliffs

• Create structures

• Create procedural worlds

• Export worlds

==============================================================================

# Secondary Goals

Future versions should support:

• Plugin marketplace

• Community brushes

• Community generators

• Collaborative editing

• GPU simulation

• Procedural node graphs

==============================================================================

# Non Goals

VoxelForge is NOT intended to become:

• A Minecraft launcher

• A game engine

• A Blender replacement

• A texture editor

• A modeling software

==============================================================================

# Success Criteria

The project is considered successful when a user can:

1.
Create a complete voxel world.

2.
Edit it interactively.

3.
Generate terrain procedurally.

4.
Export directly to Minecraft.

5.
Export directly to Bloxd.io.

6.
Never launch Minecraft during production.

==============================================================================

# Future

Every future decision must answer the following question:

"Does this make VoxelForge a better voxel engine?"

If the answer is no,
the feature should probably not exist.
